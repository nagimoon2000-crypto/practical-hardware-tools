How many clips remain open?

Read the worked answer

The two cable lines add up to 10, so no cables remain open. Only 2 of 3 clips shipped. The open balance is 1 clip.

Group by order and SKU before subtracting shipments. If D02 appears twice in a new import, compare its dispatch-line ID with the source record before releasing or cancelling a shipment.
