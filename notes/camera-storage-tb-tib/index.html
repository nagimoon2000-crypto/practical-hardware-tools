Compare decimal TB with binary TiB without losing video capacity

A recorder can display a smaller-looking capacity number without any bytes being missing. Decimal terabytes and binary tebibytes use different divisors, and they should not be mixed in a retention calculation.

All tools and notes

Convert through bytes

One decimal TB is 1,000,000,000,000 bytes. One TiB is 1,099,511,627,776 bytes. A nominal 4 TB capacity is therefore 3.637979 TiB before filesystem or other reservations. A calculator estimate of 1.45152 TB is 1.320150 TiB, expressing the same byte count.

Compare like with like

First write both required storage and usable capacity in bytes, or convert both to decimal TB. Do not subtract a TiB value from a TB value. Do not apply an extra capacity loss merely because the display switched units: the unit conversion itself does not consume storage. Actual filesystem use, reserved space and redundancy can still reduce available bytes.

Check the recorder

Find the recorder’s actual usable-byte figure and its unit convention; some interfaces use ambiguous labels. Confirm how much space remains after initialization and other applications. Compare the video requirement with that usable amount and document any required free-space reserve separately. This note addresses unit conversion only; it does not select a disk or establish endurance, redundancy or guaranteed retention.

Check the assumptions behind your calculation

Use these free worked guides to choose better inputs and avoid common interpretation mistakes.

  • Estimate camera bitrate from recorded file growth

    A resolution label is not a storage measurement. Recorded file growth over a known time interval gives a useful starting point for the bitrate input, provided you know what those bytes contain.

  • Combine cameras with different bitrates and recording schedules

    A single camera-count input assumes a common bitrate and recording schedule. For a mixed installation, calculate each group separately and add its data volume before applying a shared allowance.
